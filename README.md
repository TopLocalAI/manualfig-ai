## What is ManualFig.ai?

ManualFig.ai helps product and documentation teams turn rough source material into clean instruction figures for manuals, IFUs, assembly guides, support docs, and onboarding content.

You can start from product photos, CAD screenshots, sketches, or procedure text, then generate clear step-by-step visuals with labels, arrows, callouts, warnings, and a consistent documentation style.

## Who it is for

- Technical writers creating product manuals and user guides
- Documentation teams preparing IFU sheets, quick start guides, and installation docs
- Product and support teams turning workflows into customer-facing visuals
- Teams that need repeatable, export-ready instruction artwork without rebuilding every figure from scratch

## Key capabilities

- Generate instruction figures from product photos, CAD screenshots, sketches, and text
- Add labels, arrows, callouts, warnings, and step-by-step annotations
- Keep visual style consistent across product documentation
- Manage versioned project history for iterative figure work
- Export PNG outputs and use an SVG conversion workflow for cleaner documentation assets

## Typical use cases

- Product manuals and assembly instructions
- Medical-device IFU and regulated instruction content
- Appliance maintenance and troubleshooting guides
- Electronics setup, onboarding, and support documentation
- Internal SOPs and training materials

- 生成される図は説明用の補助イラストであり、設計図面、規制当局への提出書類、認証済み安全文書ではありません。
